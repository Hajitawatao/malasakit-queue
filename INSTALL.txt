MALASAKIT QUEUEING SYSTEM - R1MC
================================

KAILANGAN
  - XAMPP na may PHP 8.2 o mas bago (C:\xampp)
  - Internet sa unang setup lang (para i-download ang PHP packages)
  - Hindi na kailangan ng Composer o Node; kasama na ang compiled frontend.

UNANG BESES
  1. I-extract ang folder sa Desktop (o kahit saan).
  2. Buksan ang XAMPP Control Panel > START ang MySQL.
     (Hindi kailangan ang Apache.)
  3. I-right-click ang setup.bat > Run as administrator
     (administrator para mabuksan ang firewall port 88).
  4. Hintaying lumabas ang "TAPOS!".

ARAW-ARAW
  1. START ang MySQL sa XAMPP.
  2. Double-click ang start.bat
     - Dalawang naka-minimize na window ang bubukas (WEB :88 at VOICE).
       HUWAG ISARA ang mga iyon.
  3. Para patayin: stop.bat

MGA ADDRESS (palitan ang <IP> ng IP ng server, makikita sa start.bat)
  Kiosk   : http://<IP>:88/kiosk?key=<QUEUE_DEVICE_KEY sa .env>
  TV      : http://<IP>:88/display
  Counter : http://<IP>:88/login

CHROME SHORTCUTS
  Kiosk (thermal printer = default printer, 80mm, walang margin):
    chrome.exe --kiosk --kiosk-printing "http://<IP>:88/kiosk?key=..."
  TV:
    chrome.exe --kiosk --autoplay-policy=no-user-gesture-required "http://<IP>:88/display"

LOGOS
  Ilagay sa public\logos\ : doh.png, dswd.png, philhealth.png
  (Pangalan lang ang lalabas kapag wala pa.)

AUTO-START KAPAG NAG-RESTART ANG PC
  Win+R > shell:startup > maglagay ng shortcut ng start.bat
  (Dapat naka-auto-start din ang MySQL ng XAMPP: XAMPP Control Panel > Config
   > Autostart of modules > MySQL.)

BOSES - KOKORO (natural na babae, offline, libre)  << DEFAULT
  install-kokoro.bat - i-download ang Kokoro voice (isang beses, ~155 MB).
  Palitan ang boses sa .env: KOKORO_VOICE=af_heart (af_bella, af_sarah, bf_emma ...)
  start.bat nagbubukas din ng "VOICE" window: siya ang gumagawa ng boses. HUWAG ISARA.

BOSES - PIPER (backup, offline)
  install-voice.bat - i-download ang Piper at female voice (isang beses, may internet).
  Kasama na ito sa setup.bat. Patakbuhin ulit kung gusto palitan ang boses.

ELEVENLABS (Kristen voice, online, may bayad)
  setup-elevenlabs.bat - ilagay ang API key. Kailangan ng paid plan (Starter pataas).
  warm-voice.bat       - gawin na agad ang numbers 1-30 para mabilis ang unang tawag.
  Kapag walang internet o ubos ang credits, automatic na Piper ang gagamitin.

MGA SETTING (.env)
  QUEUE_WEIGHT_FAST/PRIORITY/REGULAR  - ratio ng Call Next (default 2:1:1)
  QUEUE_DEVICE_KEY                     - susi ng kiosk
  DB_PASSWORD                          - kung may password ang MySQL root

Para sa detalye ng code at database, basahin ang README.md.
